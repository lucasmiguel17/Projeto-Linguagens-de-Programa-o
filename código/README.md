# Código

Nesta pasta ficará o código-fonte do GameStock.

## Linguagem utilizada

Python.

## Funcionalidades previstas

- Cadastro de produtos.
- Consulta de produtos.
- Controle de estoque.
- Registro de vendas.
- Geração de relatórios.
- Salvamento e carregamento de dados.

## Execução

O programa será executado pelo terminal
utilizando Python.

Instruções de execução serão adicionadas
quando o desenvolvimento começar.
