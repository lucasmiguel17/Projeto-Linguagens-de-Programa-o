# 🎮 GameStock

Sistema de gerenciamento para uma loja de
videogames e jogos.

## Sobre o projeto

O GameStock é um software desenvolvido em
Python com o objetivo de auxiliar no
gerenciamento de uma loja de videogames e
jogos, facilitando o controle de produtos,
estoque e vendas.

## Objetivos

- Organizar o cadastro de produtos.
- Controlar o estoque da loja.
- Registrar e consultar vendas.
- Gerar relatórios de produtos e vendas.
- Facilitar o gerenciamento da loja.

## Tecnologias utilizadas

- Python
- Git

- Visual Studio Code
